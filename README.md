# 🎉 YEN SPECTRA 2026 – Event Registration Website

A responsive event registration website developed for **YEN SPECTRA 2026**, organized by the **Department of Computer Science, Yenepoya Institute of Arts, Science, Commerce & Management** in celebration of **International Youth Day**.

## 🌟 Features

- 🎨 Modern and responsive user interface
- 📅 Event details with date, time, venue, and participation information
- 📝 Online registration form
- 👥 Dynamic team registration for group events
- 📊 Automatic storage of registrations in Google Sheets
- 📱 Mobile-friendly design
- 🚀 Hosted using GitHub Pages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- GitHub Pages

## 📋 Registration Features

- Individual and team event registration
- Dynamic team member fields
- Event-wise registration
- Form validation
- Successful registration confirmation
- Automatic data storage in Google Sheets
